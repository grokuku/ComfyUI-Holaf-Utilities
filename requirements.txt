# === Holaf Utilities Dependencies ===
#
# This file lists external Python packages required by the Holaf Utilities extension.
# To install, run the following command in your ComfyUI's Python environment:
# pip install -r requirements.txt

# psutil is used for fetching system/process utilization (CPU, memory)
# in a cross-platform way. Required for the System Monitor.
psutil

# pywinpty provides a PTY-like interface for Windows, enabling full terminal
# functionality (resizing, colors, echo) by using the ConPTY API.
# It is only used on Windows.
pywinpty; sys_platform == 'win32'
aiofiles
orjson
watchdog

# python-xmp-toolkit is used for reading/writing XMP metadata (tags) in images.
python-xmp-toolkit

aiohttp
Pillow
pynvml

# --- Nodes imported from CUI-Holaf (fusion) ---
# numpy: tensor/image conversions in the shared node helpers and several nodes.
numpy
# spandrel: model loading for the Upscale node (AIHUpscale).
spandrel
# av (PyAV): video decoding/encoding for Load Image/Video and Save Media.
av

# --- Nodes & infrastructure imported from AIH / AI-Helper (fusion) ---
# requests: backend kw.holaf.fr calls from the AIH nodes (Elements, Enhance,
# Ideogram 4, Music...) and the sync engine.
requests
# paramiko: SFTP chunked transfers + fingerprint for the /api/aih/models routes.
paramiko
